# SleekCord

A pitch black discord theme that's sleek and modern in every way.

![Banner](https://raw.githubusercontent.com/TNT4ME/SleekCord/refs/heads/main/site/banner-raw.png)

# Features

- Background Transparency
- Custom Background Image
- Light Theme support for those who like to flashbang themselves :)

## Note for MacOS (Vencord)

To enable background transparency in MacOS, go to `Settings > Vencord > Window Vibrancy Style` and set it to one of the following:

- Selection - Transparency even when unfocused but has no blur
- HUD - No transparency when unfocused but has blur
- Titlebar - Same as HUD but has a darker tint
